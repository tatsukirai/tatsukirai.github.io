# RYM Search

Página local minimalista para gerar pesquisas da coleção do Rate Your Music.

## Como usar

1. Extraia a pasta.
2. Abra `index.html` no navegador.
3. Escolha Gênero, Artista, Ano ou Lançamento.
4. Digite o termo e pressione Enter ou clique em Pesquisar.

As pesquisas são abertas em uma nova aba.

## Configuração

O usuário está definido em `script.js`:

    const USERNAME = "HTravas";

Se quiser usar outro usuário, altere esse valor.

O projeto não possui backend, banco de dados, bibliotecas externas ou instalação necessária.
